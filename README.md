# GifViewer-v1

55体のCodex Petから、キャラクター構造（♥）と参考にしたい動き（★）を厳選する個人用GIF Assetカタログです。

## v2.2

- ホームタイトルを `GIF Asset` に変更
- 大きな `55` 表示を削除し、将来のイラスト配置用 `No Image` スペースを確保
- 進捗 `n / 55` を「つづきから」ボタン右下へ移動
- `かくにん` 一覧から ♥/♡ を直接切替可能
- `かくにん > ★ 動き` で各動作の ★/☆ を直接切替可能
- `かくにん > すべて / ♥ キャラ` でも、その確認セッションで候補になった★動作を直接切替可能
- 確認画面で選択解除しても、HOMEへ戻るまではその候補を一覧に残す
  - ♥→♡ にしても `♥ キャラ` に残る
  - ★→☆ にしても `★ 動き` に残る
  - 再選択可能
- HOMEへ戻った時点で確認候補を再計算し、現在♥または★が付いているものだけが次回の確認対象になる

## 基本操作

- カタログ：縦スクロール
- `♥`：キャラクター構造を採用
- `★`：そのActionの動きを採用
- `かくにん > ♥ キャラ`：Petを選択すると9種の動作を通常再生
- `かくにん > ★ 動き`：採用候補Actionを共通の正規化フレーム軸で同期表示
- 判定・進捗・メモ：localStorageへ自動保存
- `結果を書き出す`：`codex_pet_selection.json`
